# Test corpus

- `synthetic/` — generated ugly contracts (M0). Tracked in git.
- `golden/` — expected outputs for the synthetic set. Tracked in git.
- `real/` — anonymised documents supplied by the owner. **Git-ignored.**

No client documents, ever. Anything with a real party name in it does not
belong in this repository, anonymised or not, unless the owner has cleared it.

When Word's storage of some construct is unclear, add a minimal .docx here that
demonstrates it and read the XML. Do not guess.
